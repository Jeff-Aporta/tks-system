tk-* — visor de tiquetes en web components

Galería de componentes tk-* que pintan la documentación de un tiquete. Reusan el kit is-* (botones, tags, charts, etc.) por CDN. Cada item de la izquierda abre un preview con la API del componente y un payload de muestra.

Cómo se consume

Un solo <script type="module"> registra todos los bloques Tk. Después, cualquier <tk-block> resuelve el kind al componente correcto.

<script type="module" src="dist/cdn/tk.all.js"></script>
<tk-block></tk-block>
<script>
  const block = document.querySelector('tk-block');
  block.bloque = {
    kind: 'code',
    payload: { code: 'SELECT * FROM tiquetes;', language: 'sql' },
  };
</script>

Estructura del visor

El visor completo es <tk-view>: recibe el JSON del tiquete y arma el documento agrupado por secciones (Solicitud, Causa, Solución…).
